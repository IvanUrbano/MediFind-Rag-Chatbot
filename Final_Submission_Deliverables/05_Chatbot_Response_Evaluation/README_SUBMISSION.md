# Chatbot Response Evaluation

This deliverable contains 36 live-API cases (more than the required 10), including answerable, unknown-medicine, missing-information, and medically unsupported requests. Expected answers were built from the three PDFs. The automated baseline was 30 PASS and 6 FAIL; stricter engineer review was 19 PASS, 14 PARTIAL PASS, and 3 FAIL. These are preserved baseline results, not post-fix claims. The user's final Phase 5 manual testing is not marked complete.
