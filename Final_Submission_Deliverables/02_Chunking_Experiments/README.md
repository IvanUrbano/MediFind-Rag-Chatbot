# Chunking Experiments

Five documented runs are included. A–D hold top-k at 3; E is a top-k sensitivity control. Configuration D (800/200/top-k 3) was selected because it achieved the best MRR@3 (0.5926) and best recorded answer quality (3/9) among the tested configurations. The notebook contains saved execution outputs; the workbook contains the configuration comparison and 45 question-level rows.
