# MediFind PH Chatbot Accuracy Evaluation Deliverable

This folder contains a read-only evaluation of the live Configuration D baseline.

- `MediFind_PH_Chatbot_Response_Accuracy_Evaluation_Report.md` — comprehensive narrative report.
- `MediFind_PH_Chatbot_Response_Accuracy_Evaluation.xlsx` — full expected/actual results, quality checks, citations, root causes, and limitations.
- `run_evaluation.mjs` — reproducible 36-case live API suite.
- `test_cases.json` — fixed expected answers and PDF/page evidence.
- `raw_api_results.json` — unscored API responses.
- `automated_results.json` — deterministic automated checks.
- `reviewed_results.json` — stricter engineer adjudication.
- `SHA256SUMS.txt` — artifact checksums.

Production code, Configuration D, Chroma data, and original research results were not modified.

The user's Phase 5 manual testing is **not completed** by this deliverable.
